# 📝 ToDo App — Organize Your Day, Effortlessly.

A clean, fast & responsive ToDo web application built with pure HTML, CSS & JavaScript. Designed with a modern UI, smooth animations, and local storage support.

### ✨ Key Features
- ✅ Add, Edit & Delete Tasks Instantly
- 💾 Auto-Saves in Browser with Local Storage
- 📱 Fully Responsive - Works on Mobile, Tablet & Desktop
- 🎨 Modern UI with Glassmorphism & Smooth Animations
- 📄 Multi-Pages: Home, About, Features, FAQ & Contact
- ⚡ Lightweight & Super Fast - No Frameworks Needed

### 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, Modern JavaScript (ES6+)
- **Storage:** Browser LocalStorage API
- **Deployment:** GitHub Pages
- **Design:** Custom CSS, Flexbox, Grid
