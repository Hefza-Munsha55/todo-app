Frequently Asked Questions


Is my data saved? +
Yes! All tasks are saved in your browser's localStorage. Even after refresh or closing the tab, your tasks will remain.
Do I need internet? +
No, this is a 100% offline Vanilla JS app. It works without internet after first load.
Is it built with React? +
No, this project is built with pure Vanilla JavaScript as per Week 4 requirements. No framework used.
Can I edit a task? +
Yes, click on Edit button. The task will come back to the input field where you can update it.
